Windows x86-64 native ASM VM (WIN_X86_64)
=========================================
Release: v0.17.0-turbo.4 (2026-11-28, commit `6ed860a`; pinned QuickJS-NG 0.17.0 / 7b5f588e0f)

Overview
--------
`WIN_X86_64` is the unified source-level native register-frame assembly VM for
64-bit Windows across MSVC (`cl` + `ml64`), LLVM `clang-cl`, and MinGW-w64 GCC.
`QJS_FRAME_BACKEND=AUTO` selects `WIN_X86_64` automatically without GNU binutils
on MSVC/`clang-cl` and replaces the retired legacy COFF-adapted `WIN64` backend.

Build and verification
----------------------
  cmake -S vm -B build/win-x86_64 -G Ninja -DCMAKE_BUILD_TYPE=Release -DQJS_FRAME_BACKEND=AUTO -DQJS_PROPERTY_IC=ON
  cmake --build build/win-x86_64 --parallel
  ctest --test-dir build/win-x86_64 --output-on-failure

- ABI & Unwind: Full Win64 calling convention compliance (32-byte shadow space,
  nonvolatile GPR/XMM discipline, complete SEH `.pdata`/`.xdata` unwind metadata).
- Static CRT (`/MT`): Pass `-DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded` on MSVC;
  `vm/ci/verify_pe_imports.py` verifies `qjs.exe` and `qjsc.exe` import `KERNEL32.dll` only.
- Toolchains qualified: MSVC 14.50 (`cl` + `ml64`), `clang-cl`, and MinGW GCC 13.1.
- Pre-generated offline builds: `-DQJS_USE_PREGEN_ASM=ON -DQJS_PREGEN_DIR=<dir>/win_x86_64`
  (zero Python invocation at build time).
