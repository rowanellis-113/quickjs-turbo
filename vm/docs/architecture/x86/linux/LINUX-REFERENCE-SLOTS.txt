Qualified Linux native reference-slot replacement
===============================================

This development increment carries the accepted shared Win reference-slot
factory to measured Linux ELF/SysV. It does not change the pinned
QuickJS-NG0.15.1 bf8988f core,bytecode,public ABI,frame or root layout.
Windows factory defaults remain byte-identical;no fresh Windows compiler
build is claimed by this Linux qualification. Whole performance review
retains all original launch modes and per-case costs.

Source and ownership
--------------------
tools/elf/slot_store.py adapts tools/generate/slot-store.py with the measured
layout and a reviewed owner hash;tools/elf/generate-vm.py emits its normal
and Dirty continuations. The shared generate-register.py opt-in defaults
False and is selected only for the complete native Linux stream.
Both put/set local,argument and closure slots retain incoming alias,dup
and transfer semantics. A nonlast old reference is decremented directly.
The last-reference route captures/dups the new value,commits its slot and
PC/SP BEFORE finalization,and never rewrites the slot after a callback.
It uses existing typed JS_FrameInterpFree for original quota/publication
and GC/reentry ownership,rather than a second borrowed-release algorithm.
Dirty routes preserve their observing boundary. Unsupported or disabled
cases retain the original C opcode implementation.

Configuration and ABI
---------------------
QJS_DISABLE_NATIVE_SLOT_STORE disables the complete family by PRESENCE;
both 0 and1 disable it. The decision is cached in one existing empty
JSRuntime padding byte at normalize_has_attr+5 (349 on this qualified ABI).
No new runtime/public field,allocation or frame byte is added. Layout
extraction verifies this byte precedes normalize_u (352). SysV getenv
uses RDI/RAX while private VM RDI/RSI,target and flags use scratch32..63.
The new section borrows CFA144 and both normal/Dirty functions have FDEs.
The actual relocated public consumer naturally reached256 last-release
boundaries with coherent state/SF PC/SP and current frame,and unwound to
main. The observer never changes engine controls,memory or registers.

Layout and size
---------------
JS_LegacyCallInternal,JS_FrameVarargsSlow,JS_FrameInterpFree,numeric leaf
and unified selector retain reviewed entries,sizes and exact bytes.
Normal/Dirty register VMs retain entries/sizes;each has34 changed negative
tag branch destinations into the complete new reference-store family.
The old independent105byte insert3 continuation moves+1184 due ELF orphan
section ordering. This is NOT whole-image or whole-text identity.
New executable section1180bytes;constant env string30bytes;CLI+3288bytes.
No PGO,fixed base,padding search or core interpreter rewrite was used.
