5. Historical `v0.15.1` reference notes
   On the same Reference Host under the original `Date` harness with Stock
   QuickJS-NG 0.15.1 (`1,007.04`), `v0.15.1-turbo.8` scored `2,101.40` (monotonic
   recomputation ~`1,846`–`1,912`). Under monotonic timing, `v0.17.0-turbo.4`
   (`2,159.80` Default / `2,180.93` Density) surpasses all prior releases and
   reaches parity with Node 24 `V8 --jitless` (`2,177.85`). Prior bring-up
   worker notes live under `workers/LINUX-*.txt`.
