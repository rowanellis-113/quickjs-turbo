Shared implementation and measured ABI
---------------------------------------
The accepted call-forward normalizer, prepared C constructor and nine native
functions are reused through explicit actual-layout arguments to the common
factories. Their default Win64 output and explicit Win layout output equal the
actual qualified MinGW assembly:1418 generated rows including labels. The
prepared C factory's Windows output also matches its original generated body
exactly;Linux removes its unused leaf temporary after native classification.
The ordinary Win64 MinGW build and all307CTest/144decision receipts pass after
these shared changes. The accepted Windows SDK70638ed remains unchanged.

Linux uses actual GCC/SysV classes, fields, bitfields and inline refcount0.
The identity guard is a compiler-checked hidden ELF alias of the real original
js_function_call, not a guessed local clone or copied COFF fingerprint. A new
four-argument prepared bridge is checked against the real preprocessed
signature; JSValueConst expands to JSValue in this pinned header.

Returning probes keep the original private volatile-register convention and
receive32 separately reserved native scratch bytes. Reusing the Win home area
in the live Linux VM would overwrite its canonical TLS anchor. Returning
functions use ordinary CFA8; the forwarding caller records the32-byte change,
then restores the live VM CFA144. Direct JMP continuations retain that VM CFA.
The native VM has142 handlers and32 audited C bridge targets. No JSValue,
public type, arena state or regular128-byte JS-frame header grows.

Ownership, observable frames and unwind
---------------------------------------
Supported genuine call wrappers normalize at most64 layers. A native leaf may
return only the accepted immutable/argument/integer-add forms; it still checks
the full hypothetical frame/arena/quota geometry and exact poll/realm order.
Returned references are duplicated before the original operand owners die.
One-wrapper native constructors own all supplied arguments and missing suffix,
or borrow a proven readonly window. Missing readonly slots are padded only
within the caller's declared operand stack and actual allocation, excluding
captured tables. Mutable/unknown graphs keep independent ownership. Proven
kind7 captures retain the original detach/close lifetime from LINUX-JS-CALLS.

The shared deep descriptor normalizes once, then enters the original prepared
leaf or owned constructor. Every owning cell, local and captured-table entry
is initialized before runtime publication. No observer or failing operation
occurs between final admission and complete publication. Linux restores the
running cur_sp=NULL convention when returning from these constructors.

Non-elidable wrappers retain80-byte logical C SFs after the regular data frame.
They borrow the original pending owners, preserve native function identity,
arguments and realm poll order, and remain visible through captured-cell close
and every observable value release. Root marker2 identifies their JS child;
marker1 remains a real activation root. The common retained-context parent/take
helpers, native normal return and C exception/slow return skip/release the
complete logical chain only after cleanup. Data quota and segment cursors
account for the full tail; no native C activation is added per wrapper.

An existing no-overwrite guard retains a C-stack builtin view when logical
tails follow a frame. This matches the accepted Win window-preparation bound;
it never moves a published logical SF to create a cached view. The mixed
fixture observes40 root2 builtin stack views and0 arena-window views. A future
post-tail window design would require its own ownership/geometry/cost proof.
