Linux native public/root/child entries (development)
===================================================

The SysV public entry, zero/equal-arity roots and coherent borrowed native
children now have real ELF entries. This closes that entry dependency group,
not the entire call family, Linux port or performance/release qualification.
The accepted Win64 product and its19 upstream source pins remain unchanged.

Actual ABI and shared algorithms
--------------------------------
The independent executable probe uses this build's GCC flags, actual public
header and expanded private signature. All70checks pass. Context is RDI,
function RSI/RDX, receiver RCX/R8 and argc R9d. Internal new_target is spilled
as one complete aggregate at entrySP+8/+16; argv and flags are+24/+32. Public
argv is+8. Results are RAX/RDX. No Win64 retbuf/shadow-space ABI is assumed.

The existing128-byte JS frame,168-byte state,32-byte segment and24-byte TLS
anchor remain unchanged. Root/child primitive, own-data getter, Symbol-field
comparison and captured integer-update leaf algorithms come from unchanged
root-leaf.py/child-leaf.py factories using measured Linux fields/refcount0.
Their noncalling scratch fits exactly the128-byte SysV red zone; misses restore
every original argument before a C/constructor tail. No red-zone value survives
a C call. Returned references are duplicated before original owners can die.

The public and ordinary root constructors retain a4096-byte nonmoving arena,
sixteen weak call sites and eight replacement bytes. Their native reservation
is4936bytes with a page touch and complete CFI. Equal-arity roots cover0..3
arguments under the inherited bytecode/locals/capture/stack bounds. COPY_ARGV
owns exactly the formal cells; flags0 retain the original borrowed argv,
including non-NULL argc0. The caller realm is polled before publication/charge.

Native children retain the original coherent host cursor and borrowed-argv
proof, with a312-byte native state/barrier reservation. Compiler C owns ELF
TLS addressing; a typed accessor avoids a guessed TLS model. Shared mode,
runtime identity, committed charge, class/validation/capture, arity/capacity,
physical/logical quota and interrupt guards precede reservation/publication.
Every frame cell and live state field is initialized before runtime/TLS
publication. The common VM owns captures, native/C normal and exception pop,
cursor restoration, grown-segment ownership and final result roots.

Controls preserve original semantics
-------------------------------------
Presence,including0,disables QJS_DISABLE_NATIVE_ROOT_ENTRY,
QJS_DISABLE_NATIVE_ROOT_ZERO,QJS_DISABLE_NATIVE_ROOT_ARGS,
QJS_DISABLE_PUBLIC_ROOT,QJS_DISABLE_NATIVE_CHILD and
QJS_DISABLE_NATIVE_CHILD_LEAF. QJS_DISABLE_THIS_FIELD_LEAF retains the accepted
special case: value0 keeps getters enabled; other present values disable them.
Shared/register/frame controls retain their original fallback. Configuration
is cached without adding a public API or timing-path counter.
