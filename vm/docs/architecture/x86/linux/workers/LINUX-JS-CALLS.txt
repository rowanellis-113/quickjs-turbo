Linux owned-argument and readonly-captured calls (development)
=============================================================

js-call-r2 is a mechanism/ownership checkpoint, not a new product or a
performance baseline. All six LINUX-PORT.txt gates remain required. It also
repairs a real post-checkpoint builtin-view/argument alias defect in c-entry-r4.
The accepted Windows product70638ed remains unchanged.

Shared constructor and actual SysV route
---------------------------------------
The shared register stream already prepares scalar call metadata: cached frame
bytes, formal/local counts and the inherited initialization bit. This was not
a missing default mechanism. tools/x86/common/codegen/js-owned-missing.py now exposes
the existing constructor as a pure factory over the supplied actual layout.
Its126 accepted MinGW instruction rows remain identical. tools/x86/linux/js_calls.py
uses that factory with compiler-measured Linux types and inline refcount0.

Four direct-only native blocks add guarded owned missing arguments, the wide
missing window, the owned child constructor and readonly-captured admission.
Every supplied owning cell receives its own Dup, including repeated aliases;
the missing suffix is Undefined. Locals and captured-cell tables are initialized
before runtime SF publication. Existing capacity, stack quota, interrupt,
exception, close/pop/tail cleanup and typed legacy fallback remain in force.
The inherited wide constructor bound is128 formals. No public/state type grows,
no per-JS-call C recursion is added and no address/layout tuning is involved.

Readonly captures and naming dependency
---------------------------------------
The original64-node,65536-code-byte,4096-pool-value proof is extracted verbatim
from call-forward-owned.py. It checks all descendant bytecode constants,
including never-executed closures, against the original positive whitelist.
Unknown, mutable, eval/arguments/rest/with and over-budget graphs retain the
owned/original route. The proof uses bounded stack storage, no recursion or
allocation; the real runtime stack headroom is checked before admission.
Proven low-kind7 functions can borrow the argument window. Their captured
cells keep the original detach/close ownership when an escaping closure lives
past its caller. External closure variables and locally owned captured cells
remain distinct.

Closure name inference emits OP_set_name. Without that dependency, otherwise
eligible readonly-capture bodies returned wholly to the legacy interpreter.
The exact accepted set-name STEP uses the real JS_DefineObjectName helper;
Linux restores its running cur_sp=NULL convention after the allocating call.
The original begin/finish-C publication and exception protocol is preserved.
At this checkpoint the native VM had142 handlers and27 audited C bridges.

Builtin view correctness repair
-------------------------------
The cached128-byte view is inactive scratch that a later borrowed missing-argv
pad can reuse. Eleven formal arguments with zero actual arguments write the
Undefined tag3 into its transient-segment word at offset120. Before this fix,
the next hot or geometry-cached slice mistook that word for an owned segment
and segfaulted. Semantic/TC successes at c-entry-r4 did not cover that alias.

Every hot-window invocation and cached C geometry preparation now resets its
transient-segment owner to NULL. Geometry/lifetime validity never preserves
inactive payload bytes. Actual transient mode still stores its real segment.
The original negative is retained at js-call-r1/window-argument-diagnosis.
The same unchanged eleven-formal fixture now observes3->0 reinitialization
three times in each of the hot and geometry paths, without changing inferior
memory or diverting the borrow route. A new regression covers1..128 formals,
eight calls each, in five view modes. c-entry-r4 is superseded for correctness;
its frozen qualification records remain historical evidence.
