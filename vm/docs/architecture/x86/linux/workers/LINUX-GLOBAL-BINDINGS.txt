Linux complete GNU global binding mechanisms
============================================

The accepted GNU global-binding factory is reused in full: live own/lexical
activation hints, the two-way replacement policy, undefined mask/bucket linking
and the large-bytecode bypass. Existing BC global cells run first, including
the original resolved-cell Symbol condition. They are a separate cache layer,
not a substitute for activation hints. No cached object/shape/value pointer is
retained or dereferenced; each activation hint checks the current live binding.
