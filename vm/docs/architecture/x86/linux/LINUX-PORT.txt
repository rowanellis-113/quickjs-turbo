Six Release Completion Gates (Release Audit Contract)
-----------------------------------------------------
1. Build and packaging:
   A documented Linux product command builds the real native backend with GCC, binutils, Python,
   CMake, and Ninja. CMake reports `LINUX_X86_64` only when that backend is actually linked.
   Runtime/generated inputs carry source-bound catalogues and receipts; PIE/ASLR stays enabled.

2. Actual native execution:
   Public entry and return obey SysV ABI, including the 16-byte `JSValue` aggregate. The measured
   private VM register convention supports JS-to-JS calls, returns, tail calls, and C helpers
   without per-call C recursion. Frame ownership, quotas, interrupts, GC publication, exceptions,
   and reentry remain tested (`JS_FrameInterp` + ELF CFI).

3. Mechanism coverage:
   Every active call, property/IC, compiler, string/JSON, RegExp, array, closure, and async
   component has an explicit Linux route (`LINUX-MECHANISMS.json`) or a documented architectural
   boundary. Platform ABI, ELF, CFI, and relocation handling remain under `src/x86/linux`,
   `asm/x86/linux`, and `tools/x86/linux`.

4. Correctness and compatibility:
   Native regression, API/ABI, GC/OOM/interrupt/realm, and relocated SDK consumer tests pass.
   Full Test262 matches pinned stock QuickJS-NG `0.17.0` failure identities (`40/82,220`, `0` new).
   ELF checks verify PIE/PIC, `PT_GNU_STACK` NX, no TEXTREL, no engine `JUMP_SLOT`, and FDE unwinds.

5. Performance verification:
   Measure Stock QuickJS-NG `0.17.0`, Bellard `2026-06-04`, Node `--jitless`, and Turbo on CPU 2
   with reversed ABBA blocks (`micro57`, V8-v7, actual child Peak RSS). Record gains and costs
   honestly without PGO, padding hacks, or fixed image bases.

6. Reviewable delivery:
   Clean LF source tree, installable SDK with runnable C/C++ consumers, `QJS_USE_PREGEN_ASM`
   offline bundle support, and passing `format:check` / `test_arch_boundaries.py` / `validate_layout.py`.
