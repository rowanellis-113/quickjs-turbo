macOS x86-64 native Mach-O ASM VM (MACOS_X86_64)
==============================================
Release: v0.17.0-turbo.4 (2026-11-28, commit `6ed860a`; pinned QuickJS-NG 0.17.0 / 7b5f588e0f)

Overview
--------
`MACOS_X86_64` provides the native Mach-O register-frame assembly VM for Intel
macOS (Darwin x86-64 LP64) with Apple Clang 15+ and Xcode Command Line Tools
(`otool`, `dwarfdump`). On Apple Silicon (`Darwin arm64`) and under sanitizers or
fuzzers, `QJS_FRAME_BACKEND=AUTO` automatically falls back to `PORTABLE`.

Build and mechanism
-------------------
  bash vm/tools/x86/macos/build/product-macos.sh build/macos-x86_64 out/sdk-macos-x86_64

- Source translation: `vm/tools/x86/macos/adapt_macho.py` translates the generated
  Linux x86-64 SysV/ELF runtime and assembly outputs to Mach-O ABI/section directives
  (`_symbol` prefixes, `__TEXT/__DATA` segments, RIP-relative addressing, DWARF EH frames).
- Offline verification (`v0.17.0-turbo.4`): `adapt_macho.py` adapts `35` C/H files,
  `29` includes, and `3` assembly files (including CVM fast-segment sections
  `__TEXT,__qjs_cvm`); `vm/tests/x86/macos/test_macho_x86.py`
  (`MACHO_X86_POLICY_OK cputype=0x01000007`) and `test_arch_boundaries.py` pass.
- Darwin CI contracts verify Mach-O PIE, non-executable stack, `W^X` section hygiene,
  and complete DWARF FDE unwind coverage before packaging `macos-x86_64-sdk.tar.gz`.
- macOS ARM64 (`macos-arm64-sdk.tar.gz`, `PORTABLE` backend) is cross-compiled on
  `macos-15-intel` CI with `lipo -archs` architecture verification and downstream
  CMake consumer link validation; native Apple Silicon runtime execution tests are
  not yet run in CI.

Verified real-hardware cohort (v0.15.1-turbo.6-.8, i5-7360U)
------------------------------------------------------------
Real-hardware Darwin benchmarks were collected on MacBookPro14,1 (Intel i5-7360U,
Darwin 22.6, Apple Clang 15.0, FramePool 256) prior to the `0.17.0` port:
- V8-v7: `1,741.5` (`1.45x` vs Bellard 2026-06-04 `-O3` `1,202.0`, `1.47x` vs Turbo
  `PORTABLE` `1,185.0`; stock NG 0.15.1 scores `362.0` due to Apple Clang computed-goto codegen).
- JetStream 3.0 subset (17 cases): `1.34x` geomean vs Bellard `-O3` (`13/17` wins),
  `1.41x` vs `PORTABLE`.
- `microbench.js` (72 cases): `1.17x` geomean vs Bellard `-O3` (`39/72` wins),
  `1.37x` vs `PORTABLE`.
- Darwin 0.17.0 CI execution (`macos-x86_64` Release CTest + Test262) runs via
  `.github/workflows/ci.yml` and `.github/workflows/test262.yml`.
