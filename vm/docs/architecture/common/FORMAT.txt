Formatting and source contracts
===============================

The repository uses clang-format 22.1.8 with `.clang-format` for ordinary C/C++
and a whitespace-only formatter for checked-in GAS and MASM sources. The C
settings follow the four-space, attached-control-brace convention used by
QuickJS-NG. Assembly formatting preserves line contents and order: labels and
directives start at column one, and instructions use four spaces.

Install pinned tools and verify without modifying files:
  python -m pip install -r vm/tools/common/format/requirements.txt
  python vm/tools/common/format/install_powershell.py
  npm --prefix vm ci --ignore-scripts --no-audit --no-fund
  npm --prefix vm run format:check

Run `npm --prefix vm run format` to apply formatting fixes. `vm/tools/common/format/run.py`
automatically re-executes inside `build/format-tools/` when present.

Pinned formatters & policies
----------------------------
- C / C++ / ASM: clang-format 22.1.8 + assembly whitespace checker. The 19 pinned
  QuickJS-NG 0.17.0 upstream inputs (`vm/cmake/QuickJSUpstreamPin.cmake`), private
  Unicode snapshot, generated sources, checked-in JS snapshots, and generator C
  templates are SHA-256 protected in `vm/tools/common/format/native-frozen.json`.
- JavaScript: Prettier 3.9.10 with `.prettierrc.json`; frozen fixtures listed in
  `.prettierignore` and `vm/tools/common/format/js-frozen.json`.
- Python: Ruff 0.14.14 (`ruff.toml`, AST-equivalence verified on writes).
- CMake: cmakelang 0.6.13 (`.cmake-format.json`, token-equivalence verified).
- Shell / PowerShell / Meson: shfmt-py 4.2.0, PSScriptAnalyzer 1.24.0, Meson 1.12.1.
- Receipts & Boundaries: `format:contracts:check` (`vm/tools/common/format/contracts.py`,
  511 source receipts on `v0.17.0-turbo.1`, 0 stale) verifies input hashes and Python
  `OWNER`/`OWNER_SHA` pins without rewriting compiler fingerprints.

Run safety and layout checks before shipping changes:
  python -B vm/tests/common/test_format_contract.py
  python -B vm/tests/common/test_arch_boundaries.py
  python -B vm/tests/common/validate_layout.py --require-native
