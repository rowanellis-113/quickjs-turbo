Key v0.17.0-turbo.3 Fixes & Capabilities
----------------------------------------
- Correctness fixes over `v0.17.0-turbo.2` (with permanent CTest regressions in `test_property_ic.js`):
  1. `dtoa-fast.inc`: abort fast decimal path when explicit exponent accumulator reaches `10000` with remaining digits (prevents clamping `10^90000` strings to finite `1`).
  2. `property-ic-getter.inc`: fall back to `JS_CallFree` on nested native C getters so `Error.stack` preserves the outer JS getter frame (`get size -> get outer -> caller`).
- Performance & memory refinements verified on `v0.17.0-turbo.3`:
  1. `slice-native.inc`: fast-path `JS_TAG_STRING` receiver and `JS_TAG_INT` start/end indices in `JS_FrameStringSliceNative` (`-17.4% / -4.6% / -15.4%` on Linux `string_slice1/2/3`, verified against 3,175 edge cases matching Stock hash `1372709702`).
  2. `hybrid-gc.inc`: restore `1.5x` full-GC threshold on `_WIN32` after low-yield full collections, cutting Windows `typescript-octane` peak working set by `-32.2%` on MinGW (`220.6 -> 149.3 MiB`) and `-32.6%` on MSVC (`220.5 -> 149.8 MiB`).
- Native register-frame assembly VMs across `LINUX_X86_64`, `MACOS_X86_64`, `WIN_X86_64` (MSVC / `clang-cl` / MinGW), and `LINUX_AARCH64` (`161` native opcodes), plus `PORTABLE` auto-fallback.
