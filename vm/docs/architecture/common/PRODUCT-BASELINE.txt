Key 0.17.0 Capabilities
-----------------------
- Native register-frame assembly VMs across all four tier-1 desktop/server targets:
  `LINUX_X86_64`, `MACOS_X86_64`, `WIN_X86_64` (MSVC / `clang-cl` / MinGW), and `LINUX_AARCH64` (`glibc` & `musl`, `161` native opcodes).
- `PORTABLE` C fallback auto-selected on macOS ARM64, shared libs, Sanitizers, and `FORCE_GC_AT_MALLOC`.
- `quickjs-turbo.h` + `quickjs-turbo::qjs` CMake target: PIC-only mode (`own_bytecode_tail = QJS_TURBO_OFF`),
  low-bit tagged `property_ic_warmup`, `JS_PurgePropertyIC(rt)`, host LTO isolation, and `QJS_USE_PREGEN_ASM`.
- Native 0.17.0 + Wave 1–6c fast paths: `JSArena` string append, fast `dtoa`/`atod` (`dtoa-fast.inc` + `JS_FrameAtod` JSON worker),
  getter/string-key Property IC & root-leaf call fast paths, ARM64 `OP_push_bigint_i32` / `add_loc` / short loop latch,
  and Win64 native array length write / iterator / number-to-string / Hybrid GC supplements.
