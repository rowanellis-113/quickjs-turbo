Product directory layout (under vm/)
=====================================
Upstream QuickJS-NG 0.17.0 (`7b5f588e0f9b643e2996f291bfc861abeaceddc2`) remains
byte-for-byte unmodified at the repository root (`../`); all product work lives
under `vm/`.

Hierarchy rule inside `vm/`: `common/ | arm64/ | x86/` across `src/`, `asm/`,
`tools/`, `cmake/`, `tests/`, and `docs/architecture/`.

Owned sources (`vm/src/` & `vm/asm/`)
-------------------------------------
- Common C overlays: `src/common/{abi,array,bytecode,call,function,internal,io,
  json,kernel,linux,memory,promise,property,regexp,string,value,wire}/`
  (includes `property/inline-*.{h,inc}`, `property/fast-*.inc`,
  `value/{instanceof-fast,bigint-divrem-fast}.inc`, `call/{compound-leaf,fast-for-of-next}.inc`,
  `kernel/{fast-construct,fast-array-from}.inc`, `linux/virtual-arguments-fast.inc`,
  and `memory/hybrid-gc.{h,inc}`).
- ARM64: `src/arm64/{common,linux/abi}/` and `asm/arm64/{common,linux}/`.
- x86: `src/x86/{common,linux/abi,win64/{abi,common,internal,mingw64}}/` and
  `asm/x86/{linux,win64/{common,mingw64}}/`.

Tools & build orchestration (`vm/tools/`)
---------------------------------------
- Common: `tools/common/{abi,backports,bench,c_extract,elf,format,paths.py,modules.json,export-pregen.py}`
- ARM64: `tools/arm64/{build,verify,vm,workers,paths_arm64.py}`
- x86: `tools/x86/{common/{abi,codegen,coff_probe.py,build_tools.py,paths_x86.py},
  linux/{build,...},macos/{build,...},win64/{codegen,measure_layout_win64.py,prepare_win64_native.py}}`

CMake, tests, docs, CI (`vm/`)
------------------------------
- CMake: `cmake/{common,arm64,x86/{linux,macos,win64}}/` & `cmake/QuickJSUpstreamPin.cmake`
- Tests: `tests/{common,arm64,x86/{common,linux,macos}}/` (upstream tests stay untouched at `../tests/`)
- Docs: `docs/architecture/{common,common/subsystems,arm64,arm64/workers,x86/{linux,linux/workers,macos,win64}}/`
- Metadata & CI helpers: `VERSION`, `quickjs-turbo.h`, `src/sources.json`,
  `ci/{install_win64_mingw.py,release_version.py,test_ci_helpers.py,verify_pe_imports.py,verify_test262.py}`
  (GitHub Actions workflows live at `../.github/workflows/`).

Build artifacts belong under `../build/` and `../out/`, never inside tracked
source. `../test262/` is an optional pinned submodule. Normal builds use committed
`../gen/` snapshots and require neither Node.js nor a prior `qjs` binary.
