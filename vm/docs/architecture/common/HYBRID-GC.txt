Hybrid Reference Counting and Generational Partial Cycle GC
===============================================================

QuickJS-Turbo retains QuickJS's deterministic immediate reference counting
while replacing whole-heap cycle scanning and recursive destruction hotspots
with an integrated four-pillar memory reclamation pipeline. Upstream public
headers and struct field offsets remain unchanged.

Architecture overview
---------------------
1. Generational boundary-node partial trial-deletion:
   A single sentinel node (`JSRuntime.hybrid_gc_boundary_node`) is inserted at
   the tail of `JSRuntime.gc_obj_list` after every collection. Young objects
   allocated since the last collection sit after this boundary with a 1-bit
   `hybrid_young` flag inside `JSGCObjectHeader` (zero struct growth).
   Minor collections traverse only `O(|Young| + |OutEdges(Young)|)` without write
   barriers and fall back to full trial-deletion every 8 minor collections, when
   heap growth exceeds 1.75x post-full baseline, or near `malloc_limit`.

2. Specialized inline GC graph walker:
   `JS_HYBRID_DEFINE_WALKER` specializes decref/scan1/scan2 walks inline for
   ordinary objects and dense arrays while keeping Property IC weak
   prototype-shape edges sound (`js_hybrid_ic_minor_propagate`,
   `js_hybrid_ic_minor_restore`, `js_property_ic_gc_prune`).

3. Iterative O(1)-C-stack synchronous RC destruction:
   `js_hybrid_free_object_root` releases acyclic trees iteratively via an
   intrusive LIFO stack over `JSGCObjectHeader.link.next`, checking inline
   properties (`!qjs_inline_property_current(obj)`) and FramePool header sizes.

4. Native VM borrowed-copy & fast string/rope leaf drop:
   - Linux x86-64: `JS_LinuxHybridDropString1` and borrowed dense-array indexed
     loads (`drc_ok == 1`) keep mod-64 opcode phase alignment.
   - Windows x86-64 (`WIN_X86_64`): enabled natively via `win64-native-supplements.inc`.

Runtime & build controls
------------------------
- CMake option: `-DQJS_HYBRID_GC=ON` (enabled across `LINUX_X86_64`, `MACOS_X86_64`,
  `WIN_X86_64`, `LINUX_AARCH64`, and `PORTABLE`; also configurable via `quickjs-turbo.h`).
- Environment variables:
  - `QJS_DISABLE_HYBRID_GC=1`: disable all Hybrid GC & Fast RC paths.
  - `QJS_DISABLE_PARTIAL_CYCLE=1`: disable minor cycle collection & inline walker.
  - `QJS_DISABLE_FAST_RC=1`: disable iterative tree free, pool-size fast path, and VM leaf drops.
  - `QJS_HYBRID_GC_REPORT=1`: print JSON GC statistics to stderr at teardown.

Measured impact (Reference Linux x86-64 host)
---------------------------------------------
- Full-heap trial-deletion scans on V8-v7 reduced 85.8% (600 -> 85).
- `hybrid_bench.js`: `resident_cycle_churn` -33.56% (1.50x), `deep_tree_free` -7.37%,
  `local_slot_loop` -6.50%, `resident_acyclic_dto` -4.19%, string slices 9.6–11.0% faster.
