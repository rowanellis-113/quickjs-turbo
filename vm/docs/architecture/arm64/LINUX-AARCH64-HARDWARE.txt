===============================================================
Host: AWS Graviton2 Neoverse-N1 (Ubuntu, GCC 13.4, CPU1 serial, normal ASLR, FramePool 256).
Comparison cohort: Stock QuickJS-NG `0.17.0` (`7b5f588e0f`), Bellard QuickJS `2026-06-04` (`-O2`),
initial `v0.17.0-turbo.1` (`ref_turbo1`), and Wave 6c (`cand_w6`, with `JSArena` string append,
`dtoa-fast.inc`, `JS_FrameAtod` JSON worker, getter/string-key Property ICs, and `161` native
