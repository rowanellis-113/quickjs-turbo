Experimental AArch64 activation-owned literal and scalar opcode tier
===================================================================

The complete accepted ordinary and iterator literal owners are composed by
the shared source factory. Physical VM entry retains the existing kind3
blocked compiler-TLS owner,then owns the original24byte lazy record or864byte
full scope. The336byte legacy prefix and eight call replacement bytes are
preserved. Strong old/successor shape pins and bounded optional metadata
survive exactly this activation;all success,exception and allocation-failure
exits restore the caller pointer/flags and release every owned shape/chunk.
The owning cleanup never dereferences a completed JS frame.

All shapes,properties,atoms,original OrdSite/OrdRecord/OrdScope/OrdLazy fields,
class IDs,state padding and scalar constants are measured from actual GCC
types and checked again against the generated same-TU semantic owner. No
Win64 aggregate/register convention or private type mirror is imported.
Frame/state/public runtime sizes remain128/168/original. There is no new
Release or instrument TLS. Root scope storage and bounded cache allocations
are original mechanism costs;unchanged JS frame size is not unchanged stack
or RSS. Physical ARM speed and RSS remain unverified under QEMU.

Native define_field retains the complete original live record/site/bytecode/
atom/slot,plain extensible nonprototype object,hashed/undeleted shape and
spare-capacity guards. It activates the pinned successor shape before
weakening its pinned predecessor,transfers the only RHS owner and clears the
popped slot. Every miss leaves incoming operands/PC/SP unchanged and reaches
the exact original typed C lifetime owner through coherent publication.
Object allocation retains that original C allocator rather than a guessed
private malloc ABI. On cold empty literal sites (with ordinary/transition/spare
controls enabled), a bounded prefix of simple value/define_field pairs may
reserve 4/8/16 slots using isolated shape-hash seeds (reusing existing empty
reserved shapes for the same prototype/tier); 4/8-slot objects co-allocate
inline with JSObject under inline-properties.h without altering ordinary
JS_NewObject capacity or transitions.

Native insert2,typeof value/function/undefined and string/rope/object/number
truth cohorts retain the complete original tag,nonlast reference,HTMLDDA,
NaN/-0 and interrupt-reset rules. Existing immediate and numeric architecture
controls remain in force. Branches debit the original current-realm poll once
only after all guards. typeof object/function cases rejected by the accepted
kernel retain the complete original operator. The separate fused predicate
call classifier/value kernels and other specialized root/child scalar call
leaves remain OPEN;this tier does not claim that whole family complete.

QJS_INTERP_FRAME_LITERALS is the compile control and requires the existing
complete indexed/extended semantic owner. A missing dependency retains the

VM-hit,cache allocation faults,insert,typeof,predicate,truth/number truth and
