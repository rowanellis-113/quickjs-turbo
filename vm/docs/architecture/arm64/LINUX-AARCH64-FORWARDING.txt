Linux AArch64 forwarding -- partial native family

Opt-in Linux/glibc/GCC/AAPCS64 only. AUTO remains PORTABLE. Existing x86-64
factories and the 19 upstream source pins remain unchanged.

Implemented source owners:
  asm/arm64/common/register-forwarding.inc: observing original builtin gate,
    caller-owned 32-byte temporary lease and real CFI, child/result reload.
  asm/arm64/linux/forwarding-probe.S: exact single-wrapper integer leaf;
    same source classification into general/private child continuations.
  asm/arm64/linux/forwarding-owned.S: owned copies, readonly provided borrow,
    and readonly missing-argument padding within the declared caller stack.
  tools/arm64/forwarding.py: unchanged complete shared C normalizer,
    prepared commit body, logical tails and original typed cleanup owners.
  asm/arm64/linux/forwarding-prepared.S: bounded max64 descriptor discovery,
    primitive/argument/add leaves,complete owned children and typed C fallback.

The private constructors take (state,target bytecode,original argv,native argc)
in x0,x1,x2,w3. They make no call,change no SP/callee-saved register,and only
use the actual caller's 32-byte lease. Their geometry/strict/refcount fields
come from the emitted target contract and actual-type compiler assertions.
All failing checks precede either realm counter decrement. No allocation,
observer or fallback is permitted between commitment and full publication.
Each child reserves its regular frame plus an 80-byte logical native parent.
Locals,missing values,capture pointers and parent PC/SP/pending are initialized
before publishing state.frame and runtime.current_stack_frame. The existing
owning C return and guarded native root2 return preserve the entire logical
chain through capture close and observable finalization.

Owned arguments duplicate all actual arguments and pad through the formals.
Readonly arguments borrow the original operand window without provided-slot
writes or refcount increments. Missing padding must fit both the caller's
declared operand stack (excluding capture tables) and its actual allocation;
otherwise use the original owned-copy route. Zero-native-argc skips the same
unused first slot as the original algorithm and publishes undefined this.

QJS_INTERP_FRAME_CALL_FORWARD is the independent compilation control. Runtime
QJS_DISABLE_FRAME_CALL_FORWARD,NATIVE,OWNED,BORROW,BORROW_MISSING and existing
LEAF/PREPARE/PREPARE_OWNED controls retain process-presence semantics: 0 and1
both disable. The full variable names repeat FRAME_CALL_FORWARD_ where needed.
QJS_DISABLE_DEFERRED_FRAME_PUBLISH,REGISTER_INTERP and INTERP_FRAME remain
independent. Instrumented-only fixed TLS words0..4 retain the old C/native
observations;words5,6,7 count owned,provided and missing native producers.
Words8,9,10 count prepared leaves,typed C commits and native prepared owns. No
frame/state/runtime field,strong root or release-build counter was added.

Public fixture tests/aarch64/forward-owned.c checks seven actual execution

Natural read-only debugger proofs bind the emitted layout,actual child and
logical frames,root/pending/PC/SP,exact quota/realm polls,and preserved AAPCS64
integer/SIMD saved state. Debugger writes never force admission.

The original prepared descriptor preserves the depth/argc word,original argv
and target bytecode in the same32 private native bytes. Every wrapper must be
the real original Function.prototype.call intrinsic with exact class/proto/
magic/length guards. Original max64 and original argument bounds remain. A
leaf owns a returned reference before parent cleanup;nonleaf owns all actual
target arguments,pads formals and initializes every local/capture slot and

Tests include34 fresh-runtime same/cross-realm cohorts per control mode:heap
