Linux AArch64 complete native GNU comparison family
====================================================

The original GNU source factory supplies complete normalized Clean/Dirty
loose, strict and reference kernels. Its source hashes, constructor profile,
actual string bitfields and retained strict C fallback body are checked.
COMPARISONS-ORIGINAL-ALGORITHMS.json retains every original semantic row.
The target implementation uses actual AAPCS64 types and inline JSValue16,
string24, slice parent0/start8. No private struct or Win/SysV ABI is copied.

The register VM preserves its existing integer/number fast paths. Non-numeric
misses enter the complete added family. Strict strings preserve alias and
nonlast guards, different-length rejection, the original eight-character
bound, flat/slice/indirect views and narrow/wide/mixed comparisons. Loads stay
within the original content bounds. Heap decrements occur only after all
guards succeed; distinct owners require both counts greater than one, and
aliases require a count greater than two. Last references retain the original
C owner, finalizer order, coherent publication and complete cleanup.

The strict numeric supplement retains float/mixed-number false lanes and
NaN/-0 semantics. Object/Symbol identity uses the original independent
reference control. Loose equality preserves string delegation, null/undefined,
immediate/short-BigInt/float lanes and ordinary-object HTMLDDA checks. Coercion,
unsupported descriptors/tags, throws and last owners keep original C steps.

The independent ordinary C strict helper retains its original body. Only the
two original core calls and two generated strict opcode calls are routed.
The typed AAPCS64 identity leaf receives ctx=x0, sp=x1 and Boolean neq=w2,
consumes both slots only when their references stay positive, replaces slot0
and leaves popping to its original caller. A miss tail-enters the retained
actual-signature C fallback without changing its arguments. The leaf has no
physical frame and complete CFI. Never free the stale consumed second slot.
