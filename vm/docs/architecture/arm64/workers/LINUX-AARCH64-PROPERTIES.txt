Linux AArch64 base by-id property inline caches
==============================================

get_field,get_field2 and put_field use the existing bytecode-owned PIC slab.
The target compiler measures the actual common types,offsets,enums and flags.
No Win64 offsets,registers,private C aggregate ABI or object patch is imported.
The source gates bind property_ic_native.py,the common C cache lifetime and
the complete native ARM handler. The original cache producers/GC/epoch/shape
retention owners are unchanged. A new steady-state hit adds no allocation,
frame/state field,strong root or physical stack reservation.

All four accepted native ways are checked directly:primary and three secondary
ways. Own/prototype/negative reads retain the original shape+epoch proofs.
get duplicates before consuming its receiver;get-method retains the receiver.
Replacement rejects old-value last release,including the receiver/old-value
two-owner alias case,before changing anything. Same-capacity transitions first
activate the successor's prototype edge,then drop the predecessor shape/weak
edge,then install the owning RHS and consume the receiver. No native hit can
call C,allocate,collect or release a last reference. Misses retain unchanged
PC/SP and all operands for the exact original observing C learner.

The native semantic fixture observes256 get+256 get-method+256 replacement
hits,including576 secondary-way hits. A passive opcode histogram proves zero
C execution for every property opcode in the warm panel. Its256 remaining
opcode steps are all original OP_return ownership continuations;the natural
first one is independently recorded by a read-only debugger. This is not a
claim that all unrelated return mechanisms are complete.

128-trial cohort contains8 explicit collections of orphaned cache proofs:

The allocation/growth cohort takes128 original C put_field executions and no

Further checks include64 live prototype data replacements,32 negative hits,
descriptor conversion/deletion/reinstallation,32 getter GC callbacks,original
