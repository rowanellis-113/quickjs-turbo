Build & Architecture
--------------------
- Owned code lives under `vm/asm/arm64/`, `vm/src/arm64/`, and `vm/tools/arm64/`.
- Wrapper (native ARM64 or x86 cross + QEMU):
    bash vm/tools/arm64/build/product-linux-aarch64.sh build/arm64 out/sdk-arm64
- CMake `AUTO` automatically selects `LINUX_AARCH64` on supported Linux AArch64 (`glibc`
  & `musl`) hosts with GCC 13/14+ and falls back to `PORTABLE` under sanitizers, fuzzers,
  shared libraries, or BTI/PAC-default toolchains. `JS_FrameInterp` is strictly 64-byte aligned
  via `check_vm.py` (`161` native opcodes, full FDE, PIE, NX, `no-WX`).
- Waves A1–A3 (`v0.17.0-turbo.4`) add: zero-spill native AArch64 `JS_CVMRunFastSegment`
  coroutine executor (`cvm_fast_arm64.py`, with TypedArray `class_id` and `is_HTMLDDA`
  guards), widened modern-JS extra-op admission + zero-exit try/catch ASM + direct hybrid
  string1 drop, Tier-5 straight-line VA constructor compiler (`fast-construct.inc`), inline
  compound-leaf hot paths, and zero-shift ASM island layout.
- Public `quickjs.h` ABI, installed `quickjs-turbo::qjs` CMake consumers, and
  `QJS_USE_PREGEN_ASM=ON` Python-free builds (`linux_aarch64`) are fully supported.
  See `../common/ABI-AND-BASELINE-JIT.txt` for the pinned register-frame ABI contract
  (`x19..x27`) and proposed optional Baseline JIT design.
