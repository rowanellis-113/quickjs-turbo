ABI Contract & Proposed Opt-In Baseline JIT Roadmap (Future · Not Shipped) Expand ▾

Shipping Two-Layer ABI

  • Unmodified quickjs.h public C ABI & BC_VERSION 29 wire format.
  • Callee-saved register-frame ABI + Clean/Dirty lazy safepoint publication.
  • 511 SHA-256 build receipts, DWARF CFI, CET endbr64, and Win64 SEH.

Proposed Opt-In Baseline JIT (Roadmap Only)

  • Direct JSFunctionBytecode → Copy-and-Patch stencils (zero AST, keeps 96.3 KiB cold heap).
  • Zero-bridge interop with native ASM VM, direct-baked Property ICs, and Loop OSR.
  • Strictly opt-in (RW → RX only); default stays 0 RWX / Zero JIT.
