Architecture & Advantages

Why QuickJS-Turbo?

Built for production hosts that want QuickJS's tiny footprint, instant cold start, and strict security invariants — without leaving 1.5×–6.1× execution speed on the table.

01 · ZERO JIT / W^X

Fast Where JITs Are Banned

Ahead-of-time assembly VMs require zero executable heap pages. Ships with complete DWARF CFI / Win64 SEH unwind tables for iOS, consoles, locked-down containers, and edge workers.

PIE · NX stack · 0 RWX pages · native stack traces
02 · REGISTER-FRAME VM

Native Dispatch & Adaptive ICs

Replaces the indirect C switch loop with register-pinned assembly dispatch, getter/string-key Property ICs, and co-allocated inline object properties across x86-64 and ARM64.

json-stringify 6.09× · RegExp 4.95× · prop_read 3.31× · typed_array 2.84×
03 · NUMERIC & RUNTIME FAST PATHS

Fast dtoa/atod, JSON & Strings

Adds fast float/int conversion (dtoa-fast + JS_FrameAtod JSON worker), JSArena string-append, Map/Set string hashing, and capability-free async across Linux x86-64 and Graviton2 ARM64.

float_to_string 4.92× · string_to_float 2.95× · micro57 beats V8 --jitless
04 · HYBRID RC + GC

Deterministic RC, 86% Fewer Scans

Keeps QuickJS's immediate reference counting while adding generational boundary-node partial cycle collection and iterative O(1)-C-stack object reclamation.

Cycle scans -85.8% · cyclic churn 1.50× · 2.94×–8.0× lower RSS vs V8
05 · HIGH-DENSITY CONTROL

Zero Cold Bloat & Slab Purge

Via quickjs-turbo.h: disable own_bytecode tails while keeping native Property ICs, defer IC allocation with tagged warmup (+0 B struct growth), and purge idle worker slabs on demand.

98.6 KiB empty runtime · 500-fn heap -26% (0 IC slabs) · JS_PurgePropertyIC

Upstream QuickJS-NG 0.17.0 remains byte-for-byte pristine at repo root. Drop-in compatible with txiki.js v26.11.0 (BC_VERSION 29); quickjs-turbo::qjs isolates host LTO and supports Python-free pregen builds.

ABI Contract & Execution Roadmap

Verified Register-Frame ABI & Optional Baseline JIT

QuickJS-Turbo separates its immutable public C ABI from an internal register-frame execution ABI — delivering strict zero-RWX safety today while providing ~70% of the runtime substrate for an opt-in, zero-AST Baseline JIT directly over QuickJS bytecode.

Two-Layer ABI Contract

Shipping today across Linux x86-64, ARM64, macOS, and Windows

Production Invariant
  • 100% Drop-In Public C ABI: Unmodified quickjs.h, 16 B JSValue representation, and BC_VERSION 29 wire format verified on txiki.js v26.11.0; all tuning in quickjs-turbo.h is strictly additive.
  • Pinned Register-Frame ABI: Callee-saved hardware pinning (x19 state, x20 PC, x21 SP, x22 frame, x23 locals, x24 args on AArch64; equivalent x86-64 SysV/Mach-O/Win64 contract) over the contiguous JSFrame arena.
  • Clean/Dirty Lazy Publication: Fast paths skip cur_pc/cur_sp writes until call, GC, exception, or finalizer safepoints, pre-validated by FRAME_KIND and a jump-target boundaries bitmap.
  • Fail-Closed Build Contracts: core-fields.json + 511 SHA-256 ABI receipts, full DWARF CFI FDEs, and Win64 SEH .pdata/.xdata unwind tables.

Optional Bytecode-Driven Baseline JIT

Zero AST · Copy-and-Patch Stencils · Strict W^X Opt-In Tier

Architecture Roadmap

Hardware PMU profiling shows JS_FrameInterp still accounts for 53%–98% of execution cycles (dispatch, operand decode, and [sp] stack traffic). An opt-in Baseline JIT eliminates that tax directly on the existing ABI — keeping the 0 RWX ASM VM as default:

01
Direct Bytecode (No AST): Compiles JSFunctionBytecode linearly — preserving the 98.6 KiB cold heap, sub-ms parse, and 1:1 pc mapping for OSR/exceptions.
02
1-Pass Virtual Stack + Copy-and-Patch Stencils: Offline-verified stencils + 2–4 reg basic-block TOS cache fold get_loc + add + if_false without [sp] ping-pong or indirect dispatch.
03
Zero-Bridge ABI & Direct-Baked ICs: Shares JSFrame, Clean/Dirty bailouts, and Hybrid GC; bakes Property IC slot pointers PC/RIP-relatively and adds Loop OSR.
04
Strict W^X & Hotness Gate: Hotness threshold (64–128) keeps cold scripts at 0 B JIT memory; bounded Code Arena transitions RW → RX (never simultaneous RWX).
Phased gates: Phase 0 PoC (≥1.35× loops) → Phase 1 IC/Call → Phase 2 x86/ARM64 + Test262 ABI-AND-BASELINE-JIT.txt ↗
